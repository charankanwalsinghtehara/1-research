Machine Learning-Based Aqueous Solubility Prediction Using Molecular Descriptors and Graph-Based Features

Undergraduate Student (B.Tech CSE)
Department of Computer Science and Engineering
Abstract

Aqueous solubility (log S) is a fundamental physicochemical property in drug discovery, environmental science, and chemical engineering. Traditional experimental methods for determining solubility are time-consuming, expensive, and impractical for large compound libraries. This paper presents an automated machine learning framework utilizing RDKit-extracted molecular descriptors and structural representations to predict aqueous solubility. Using the benchmark ESOL dataset, we evaluate multiple machine learning algorithms—including Random Forest, Gradient Boosting, and Support Vector Regressors. Our best-performing model achieves strong predictive performance, evaluated using metrics such as Mean Absolute Error (MAE), Root Mean Square Error (RMSE), and the Coefficient of Determination (R²). The entire pipeline is integrated into an interactive Streamlit web application for real-time inference and visualization.

Keywords: Aqueous Solubility, Machine Learning, RDKit, Cheminformatics, QSAR, Streamlit.

I. Introduction

The prediction of molecular properties is a cornerstone of early-stage drug discovery and chemical safety assessment. Aqueous solubility directly influences a drug candidate's absorption, distribution, metabolism, and excretion (ADME) profile. Compounds with poor solubility often fail clinical trials due to inadequate bioavailability.

While experimental assays provide precise measurements, they cannot keep pace with the vast combinatorial space of newly synthesized molecules. Consequently, Quantitative Structure-Property Relationship (QSPR) models have emerged as a vital computational alternative. By leveraging machine learning algorithms, computational models map molecular structures—represented through topological, constitutional, and electronic descriptors—to continuous property values such as log S.

This research presents an end-to-end machine learning pipeline for aqueous solubility prediction that bridges cheminformatics and software engineering through an interactive web-based deployment.

II. Related Work

Early computational approaches relied on linear regression models using simple hydrophobic descriptors like octanol-water partition coefficients (log P) and molecular weight. Delaney introduced the ESOL (Estimated SOLubility) dataset, establishing a benchmark linear regression model based on four molecular properties: log P, molecular weight, polar surface area, and rotatable bonds.

Recent advancements have shifted toward non-linear machine learning models, such as ensemble methods (Random Forests and Gradient Boosting) and deep learning architectures (Graph Neural Networks). These advanced models capture complex, non-linear atomic interactions and structural features that traditional linear equations miss.

III. Dataset and Methodology

A. Dataset Description

The model is trained and evaluated using the ESOL dataset (Delaney, 2004), which contains logarithmic aqueous solubility values (log S) paired with simplified molecular-input line-entry system (SMILES) strings for thousands of chemical compounds.

B. Feature Extraction via RDKit

Raw SMILES strings cannot be fed directly into standard machine learning algorithms. We utilize RDKit, an open-source cheminformatics software library, to parse molecular graphs and extract numerical feature vectors (molecular descriptors). Key descriptors include:

  • Constitutional Descriptors: Molecular weight, atom counts, and bond counts.
  • Topological & Connectivity Indices: Chi indices and valence connectivity.
  • Physicochemical Properties: Estimated log P and topological polar surface area (TPSA).

C. Data Preprocessing & Splitting

Missing SMILES or parsing errors are handled via imputation, followed by standardization of feature vectors to zero mean and unit variance. Data is partitioned into training, validation, and test sets using both random splits and scaffold-based splitting to evaluate out-of-distribution generalization.

IV. System Architecture and Implementation

The project architecture is divided into modular pipelines:

  • Data Pipeline (data_pipeline.py): Handles SMILES parsing, descriptor extraction, data cleaning, and splitting.
  • Model Training & Comparison (model_comparison.py): Trains various regressors, tunes hyperparameters, and logs performance metrics.
  • Inference Engine (solubility_project.py & Saved Model): Serializes the optimal model using Joblib (solubility_model.joblib) for fast prediction.
  • User Interface (app.py): An interactive Streamlit web app allowing users to input SMILES strings and instantly visualize predicted solubility alongside molecular properties.

V. Experimental Setup and Evaluation Metrics

A. Evaluation Metrics

Performance is assessed using three standard regression metrics:

  • Mean Absolute Error (MAE): Measures the average magnitude of absolute errors.
    • MAE = (1 / n) * Σ |yi - ŷi|
  • Root Mean Square Error (RMSE): Penalizes larger errors more heavily.
    • RMSE = √((1 / n) * Σ (yi - ŷi)²)
  • Coefficient of Determination (R²): Measures the proportion of variance.
    • R² = 1 - [ Σ (yi - ŷi)² / Σ (yi - ȳ)² ]

B. Experimental Results

Ensemble regressors consistently outperformed baseline linear models, achieving lower MAE and RMSE values. Evaluation on held-out test splits confirmed robust generalization, with parity plots demonstrating tight clustering around the ideal y = ŷ line.

VI. Discussion and Limitations

RDKit molecular descriptors effectively capture structural determinants of solubility such as lipophilicity and molecular size. However, domain applicability remains limited to small organic molecules; accuracy may drop for large macromolecules, polymers, or complex organometallic compounds.

VII. Conclusion

This paper presented an automated, end-to-end machine learning pipeline for predicting aqueous solubility from molecular structures. By combining RDKit feature extraction, rigorous model comparison, and a Streamlit deployment interface, the system provides a practical tool for rapid property screening. Future iterations will explore graph deep learning architectures to further enhance prediction accuracy.
